# OneClick Organizer

파스텔 감성의 반응형 디지털 자료 정리 웹사이트입니다. 별도 설치나 서버 없이 HTML, CSS, JavaScript로 실행할 수 있습니다.

## 실행 방법
1. `index.html`, `style.css`, `app.js` 파일을 같은 폴더에 둡니다.
2. `index.html`을 Chrome, Edge, Firefox 등 최신 브라우저에서 엽니다.
3. 처음 실행하면 예시 자료가 표시됩니다. 카드의 `×` 버튼으로 삭제하고 본인의 자료를 추가해 보세요.

일부 브라우저 보안 정책이나 파일 접근 설정 때문에 동작이 제한된다면 VS Code의 Live Server 확장으로 `index.html`을 실행하세요.

## 주요 기능
- 링크와 메모 추가·수정·삭제
- 브라우저 `localStorage`에 자동 저장
- 제목·설명·URL·카테고리·태그 통합 검색
- 키워드 기반 카테고리 자동 추천
- URL 정규화 기반 중복 링크 감지
- 즐겨찾기, 최근 추가, 카테고리별 필터
- 최근 추가순·오래된 순·제목순·즐겨찾기 우선 정렬
- JSON 백업 내보내기 및 백업 불러오기
- 카드/목록 보기, 모바일 반응형 레이아웃

## 데이터 저장과 개인정보
자료는 현재 브라우저의 `localStorage`에 저장됩니다. 같은 브라우저·같은 기기에서만 기본적으로 접근할 수 있습니다. 브라우저 데이터를 지우면 저장 자료가 사라질 수 있으므로 사이드바의 **자료 백업하기** 기능을 이용해 JSON 파일을 별도로 보관하세요. 이 버전은 계정이나 서버로 자료를 전송하지 않습니다.

## 테스트 체크리스트
- [ ] 링크를 추가하면 카드에 표시되고 새로고침 후에도 유지되는가?
- [ ] 메모를 추가·수정·삭제할 수 있는가?
- [ ] 검색어로 제목, 설명, 태그, URL이 검색되는가?
- [ ] 자동 추천 카테고리가 제목·설명·태그의 키워드에 따라 바뀌는가?
- [ ] 같은 URL을 다시 추가하면 중복 경고가 나오는가?
- [ ] `https://example.com`과 `https://example.com/`가 중복으로 인식되는가?
- [ ] 즐겨찾기, 카테고리, 최근 추가 필터가 작동하는가?
- [ ] JSON 백업을 내보낸 뒤 다시 불러올 수 있는가?
- [ ] 모바일 화면에서 메뉴, 폼, 카드가 화면 밖으로 넘치지 않는가?

## 알려진 제한
- 자동 분류는 AI가 아니라 `app.js`의 키워드 규칙으로 동작합니다. 키워드는 `CATEGORIES` 배열에서 수정할 수 있습니다.
- 중복 감지는 URL의 해시와 끝 슬래시 등을 정리해 비교합니다. 서로 다른 추적 매개변수나 별칭 도메인은 별개 링크로 남을 수 있습니다.
- 사이트 제목이나 설명을 URL에서 자동으로 가져오지는 않습니다. 외부 페이지 접근은 CORS 등 브라우저 제한이 있기 때문에, 이 버전에서는 제목과 설명을 사용자가 입력합니다.
- 여러 기기 동기화, 로그인, 협업을 추가하려면 백엔드와 데이터베이스가 필요합니다.
